Cloud Projekt – Azure Static Website

Voraussetzungen
- Azure Account
- Terraform
- Azure CLI

Setup
1. Azure Login
   az login

2. In Terraform-Ordner wechseln
   cd terraform

3. Terraform initialisieren
   terraform init

4. Konfiguration prüfen
   terraform validate
   terraform plan

5. Infrastruktur bereitstellen
   terraform apply

6. Website aufrufen
   → URL aus dem Terraform-Output
